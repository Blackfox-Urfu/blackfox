# Классификация сообщений из Telegram

Проект занимается автоматической классификацией сообщений из Telegram на рекламные и нерекламные с использованием методов машинного обучения.

---

## 1. Цель проекта

Определить, является ли сообщение из Telegram рекламным, и предоставить инструмент для фильтрации рекламных сообщений в чатах и каналах.

---

## 2. Основные этапы проекта

### 2.1. Загрузка данных
- Данные представляют собой файлы JSON с текстами рекламных и нерекламных сообщений.
- Сообщения извлекаются из структур файлов и подготавливаются для дальнейшей обработки.

### 2.2. Предобработка данных
- Очистка текста от ненужных символов (переносов строк, HTML-тегов и др.).
- Выделение текста из сложных структур сообщений Telegram.

### 2.3. Формирование выборок
- Каждому сообщению присваивается метка:
  - `1` — рекламное сообщение.
  - `0` — нерекламное сообщение.
- Объединение данных в единый набор для обучения и тестирования.

### 2.4. Разделение данных
- **Обучающая выборка**: используется для тренировки моделей.
- **Тестовая выборка**: применяется для проверки точности классификации.

### 2.5. Векторизация текста
- Преобразование текста в числовой вид с помощью TF-IDF (термин-фреквенси-инверс-документ-фреквенси).

### 2.6. Балансировка данных
- Для борьбы с дисбалансом между рекламными и нерекламными сообщениями применяется метод SMOTE.

### 2.7. Обучение моделей
### 2.7. Обучение моделей

В проекте рассматриваются к применению три основные модели машинного обучения: **Случайный лес**, **Градиентный бустинг**, и **Нейронная сеть**. Ниже описаны их особенности и подходы к обучению.

#### **Случайный лес**:

- Построен на ансамбле деревьев решений, обучаемых на случайных подвыборках данных.
- Гиперпараметры (количество деревьев, глубина, минимальное число образцов для разбиения и др.) оптимизируются с помощью Optuna (Оптимизация Байеса - поиск лучших параметров на основе исторических оценок точности).
- Для предотвращения переобучения используется ограничение на глубину деревьев.
- Устойчив к шуму и дисбалансу данных благодаря bagging-методу(независимое обучение нескольких моделей по случайным данным с последующим объединением данных).
- Данные предварительно векторизуются (преобразование данных в числовые векторы) с помощью **TF-IDF**, а затем балансируются с использованием **SMOTE** для борьбы с дисбалансом классов.

#### **Градиентный бустинг**:

- Модель построена с использованием библиотеки **CatBoost**.
- Используется подход оптимизации гиперпараметров с помощью библиотеки **Optuna**, включая такие параметры, как:
    - **Количество итераций**: количество проходов бустинга.
    - **Глубина деревьев**: максимальная глубина, используемая в деревьях.
    - **Скорость обучения**: влияет на размер корректировок весов деревьев.
    - **L2-регуляризация**:  параметр регуляризации для предотвращения переобучения.
    - **Функция потерь**: выбор из категорий `MultiClass` и `MultiClassOneVsAll`.
- Для обучения и прогнозирования используется **ускорение на GPU**.
- Данные предварительно векторизуются (преобразование данных в числовые векторы) с помощью **TF-IDF**, а затем балансируются с использованием **SMOTE** для борьбы с дисбалансом классов.
- Финальная модель обучается на оптимальных гиперпараметрах, полученных в процессе оптимизации, и оценивается с использованием метрик `accuracy`, `classification_report`, и `confusion_matrix`.

#### **Нейронная сеть с использованием TensorFlow и Optuna**:

- Архитектура представлена многослойным персептроном с `Dense`-слоями.
- Регуляризация достигается с помощью **Dropout** (выключение определенной доли нейронов во время обучения для предотвращения переобучения).
- Для токенизации текста используется `Tokenizer` из `tensorflow.keras.preprocessing.text`.
- Векторизация и нормализация текстовых данных проводятся с помощью `pad_sequences`.
- Гиперпараметры, включая количество слоев, dropout, размер batch, скорость обучения и др., оптимизируются с помощью **Optuna**.
- Для предотвращения переобучения применяется метод **ранней остановки** (`EarlyStopping`) во время обучения, если в процессе не видно улучшений
- Используется взвешивание классов для борьбы с дисбалансом.

Каждая из моделей обучается и тестируется с использованием данных, полученных из JSON-файлов экспорта историй наших телеграмм каналов с собранными данными. Далее проводится их векторизация, балансировка и оптимизация гиперпараметров для достижения наилучшего результата на тестовых данных.


### 2.8. Оценка качества моделей
- **Метрики**:
  - Точность (`accuracy`).
  - Отчет классификации (`classification report`).
  - Матрица ошибок (`confusion matrix`).

### 2.9. Сохранение модели
- Лучшая модель и векторизатор сохраняются на диск для использования в будущем.

## 3. Использование

- Сохраненная модель используется для классификации новых сообщений.
- Проект интегрирован с Telegram-ботом для автоматической модерации чатов и каналов.

---

## 4. Описание Telegram-бота

### 4.1. Функционал
#### Для btb
1. Прием входящих сообщений из чата.
2. Классификация сообщений (реклама/нереклама).
3. Автоматическая модерация:
   - Удаление рекламных сообщений.
   - Отправка предупреждений пользователям.
4. Генерация отчетов для администраторов:
   - Количество рекламных сообщений.
   - Подробная статистика.
#### Для btc 
1. Парсинг постов из канала.
2. Классификация сообщений (реклама/нереклама).
3. Автоматическая модерация:
	* Скрытие сообщений
	* Сохранение в статистику 
### 4.2. Настройки
- Включение/выключение модерации.
- Настройка чувствительности классификатора.
- Управление списком разрешенных тем и ключевых слов.

### 4.3. Взаимодействие с ботом
- Команды:
  - `/start` — запуск бота.
  - `/status` — проверка состояния бота.
  - `/report` — запрос отчета о модерации.
