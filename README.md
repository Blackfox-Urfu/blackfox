# Классификация сообщений из Telegram

Этот проект занимается автоматической классификацией сообщений из Telegram на рекламные и нерекламные.

## 1. Цель проекта
Определить, какое сообщение из Telegram является рекламным, а какое — нет. Для этого используется машинное обучение и несколько моделей для обработки данных.

## 2. Основные шаги

### 2.1. Загрузка данных
Данные представляют собой файлы JSON, содержащие сообщения из Telegram. В одном файле находятся рекламные сообщения, в другом — нерекламные. Проект считывает эти файлы и извлекает текст сообщений.

### 2.2. Предобработка данных
Перед тем как данные можно будет использовать, сообщения нужно подготовить:
- Очистить текст от ненужных символов, таких как переносы строк.
- Извлечь текст из сложных структур сообщений Telegram (например, если текст сообщения разделен на части).

### 2.3. Формирование выборок
Для обучения модели проект объединяет все рекламные и нерекламные сообщения в один набор данных. Каждому сообщению присваивается метка: 1 — если сообщение рекламное, и 0 — если нерекламное.

### 2.4. Разделение на обучающую и тестовую выборки
Данные делятся на две части:
- **Обучающая выборка**: данные, которые используются для тренировки модели.
- **Тестовая выборка**: данные, на которых проверяется, насколько хорошо модель научилась классифицировать сообщения.

### 2.5. Векторизация текста
Компьютер не понимает текст напрямую, поэтому нужно преобразовать текст в числа. Для этого используется метод **TF-IDF** (частота встречаемости слов), который преобразует текст в числовую форму, удобную для работы моделей.

### 2.6. Балансировка данных
Иногда рекламных сообщений может быть меньше, чем нерекламных, что может затруднить обучение модели. Чтобы это исправить, используется метод **SMOTE** — он добавляет синтетические примеры рекламных сообщений, чтобы их количество уравновесилось.

### 2.7. Обучение моделей
Проект использует три разных модели для обучения:
- **Логистическая регрессия**.
- **Случайный лес**.
- **Градиентный бустинг**.

Каждая из этих моделей обучается на рекламных и нерекламных сообщениях.

### 2.8. Оценка качества моделей
После обучения модели проверяются на тестовых данных. Для каждой модели рассчитываются следующие метрики:
- **Точность**: показывает, насколько правильно модель классифицировала сообщения.
- **Отчет классификации**: дает подробную информацию о том, насколько модель была точна для каждой категории (рекламные и нерекламные сообщения).
- **Матрица ошибок**: помогает увидеть, сколько сообщений было правильно и неправильно классифицировано.

### 2.9. Сохранение лучшей модели
После того как все модели протестированы, сохраняется лучшая модель и инструмент, который преобразовывает текст в числа (векторизатор). Они сохраняются в файлы, чтобы их можно было использовать в будущем для классификации новых сообщений.

## 3. Использование
Сохраненную модель можно применить для анализа новых сообщений из Telegram и автоматически определять, какие из них рекламные, а какие — нет.

## 4. Зачем это нужно?

Проект необходим для автоматической фильтрации и классификации сообщений в Telegram-чатах и каналах. Это особенно полезно для:

- **Автоматизации модерации**: Бот может помочь администраторам Telegram-каналов и групп автоматически фильтровать рекламные сообщения, что упрощает управление чатом и снижает количество спама.
  
- **Анализа контента**: Если вам нужно проанализировать содержимое сообщений в больших чатах, такой инструмент позволит быстро определить, какие сообщения несут рекламный характер, и сэкономить время на ручной проверке.

- **Фильтрации спама**: В группах или каналах, где существует проблема с большим количеством рекламных сообщений, бот может автоматически маркировать или удалять такие сообщения, сохраняя чистоту обсуждений и улучшая пользовательский опыт.

## 5. Описание бота

### 5.1. Функционал бота

Telegram-бот, интегрированный с моделью машинного обучения, будет выполнять следующие функции:

1. **Обработка входящих сообщений**: 
   - Бот будет принимать сообщения от пользователей или группы, в которой он добавлен.
   
2. **Классификация сообщений**:
   - Бот использует обученную модель для анализа текста каждого входящего сообщения и определяет, является ли оно рекламным или нет.
   
3. **Модерация чатов**:
   - Если сообщение классифицировано как реклама, бот может выполнять заранее настроенные действия, такие как удаление сообщения, отправка предупреждения пользователю или пометка сообщения для модератора.
   
4. **Отчеты и уведомления**:
   - Бот может отправлять уведомления администраторам о количестве рекламных сообщений или предоставлять статистику по работе за определенный период (например, сколько сообщений было помечено как реклама за день или неделю).

5. **Обучение и обновление модели**:
   - Бот может периодически обновлять свою модель, получая новые данные о сообщениях и обучаясь на них для улучшения точности классификации.

### 5.2. Взаимодействие с ботом

1. **Добавление бота в группу или канал**:
   - Бота можно пригласить в любую группу или канал. После добавления он будет отслеживать все поступающие сообщения и анализировать их.

2. **Команды для пользователей**:
   - Пользователи могут взаимодействовать с ботом с помощью текстовых команд. Например:
     - `/start` — запуск бота.
     - `/status` — проверка активности бота и его состояния.
     - `/report` — запросить отчет о количестве рекламных сообщений.
  
3. **Действия по умолчанию**:
   - Бот автоматически анализирует сообщения в реальном времени. При обнаружении рекламы он может:
     - Удалить сообщение.
     - Отправить предупреждение пользователю.
     - Сообщить администратору о нарушении.
  
4. **Настройки администраторов**:
   - Администраторы могут настраивать правила и действия бота, например:
     - Включение или отключение автоматического удаления рекламы.
     - Настройка уровня чувствительности (насколько строго бот будет классифицировать сообщения как рекламные).
     - Просмотр детальных отчетов по всем рекламным сообщениям.

5. **Логи и отчеты**:
   - Бот может сохранять логи всех действий и предоставлять отчет по запросу, чтобы администраторы могли проанализировать активность и работу модели.

### 5.3. Возможности улучшения

- **Интерактивное обучение**: Администраторы могут вручную помогать боту улучшать точность, указывая, если бот ошибочно классифицировал сообщение.
  
- **Гибкие правила модерации**: Бот может работать с различными наборами правил в зависимости от контекста группы или канала (например, в разных группах могут быть разные требования к модерации рекламы).
  
- **Интеграция с внешними системами**: Бот может быть интегрирован с другими платформами и системами для анализа больших объемов сообщений и отчетов о рекламе.

## 6. Описание стека технологий

### 6.1. Язык программирования
- **Python** — язык, используемый для обработки данных, обучения моделей и предсказаний. Он популярен в области машинного обучения благодаря широкому выбору библиотек.

### 6.2. Библиотеки

1. **JSON** — для работы с файлами сообщений Telegram, которые хранятся в формате JSON.
2. **NumPy** — для работы с массивами данных и их эффективной обработкой.
3. **Scikit-learn** — основная библиотека для машинного обучения:
   - **TfidfVectorizer** — для преобразования текста в числовую форму.
   - **LogisticRegression, RandomForestClassifier, GradientBoostingClassifier** — модели для классификации сообщений.
   - **train_test_split** — для разделения данных на обучающую и тестовую выборки.
   - **GridSearchCV** — для подбора наилучших гиперпараметров моделей.
   - **accuracy_score, classification_report, confusion_matrix** — для оценки качества моделей.
4. **Imbalanced-learn (imblearn)** — библиотека для работы с несбалансированными данными. Используется метод **SMOTE** для увеличения количества рекламных сообщений, чтобы уравновесить классы.
5. **Seaborn** — для визуализации данных (например, построения графиков матрицы ошибок).
6. **Joblib** — для сохранения обученной модели и векторизатора на диск.
7. **os** — для работы с путями файлов и директорий.
8. **datetime** — для добавления временных меток (например, в процессе сохранения данных).

## 7. Планируемые и потенциальные улучшения

1. **Автоматическая категоризация контента**  
   Добавить функцию автоматической категоризации каналов. Это поможет системе распознавать контекст публикаций. Например, если развлекательный канал "Двач" публикует пост со статистикой и упоминанием торговой платформы (например, "Авито"), система сможет классифицировать такой пост правильно, без ошибки.

2. **Распознавание фото и видео**  
   В некоторых случаях текстовый анализ может быть недостаточен для точного определения рекламного характера поста. Планируется внедрение визуального анализа изображений и видео для повышения точности, будет ипользоваться простая классификация и распознавание текста. Однако нужно будет решить, включать ли эту функциональность для всех постов, так как это может быть спорным вопросом с точки зрения эффективности и затрат.

   Так как для классификации изображений и видео потребуется использовать библиотеку TensorFlow, логичным шагом было бы перевести все процессы в эту среду.
