BLACKFOX API

Нейросетевой анализ контента: детекция рекламы и порнографических материалов

О проекте

В основе проекта лежит мощный API для анализа контента. Мы используем эффективные алгоритмы машинного обучения (TF-IDF + нейронные сети для текста, ResNet для изображений) для точной и быстрой классификации.

Пример использования: Telegram Ad Block Extension ↗

POST /api/classify_message/

https://blackfoxus.ru/api/classify_message/

Мультимодальный анализ: проверяет текст и/или картинку на наличие рекламы.

ПараметрТипОписание
textstringТекст сообщения
imagefileФайл изображения (jpg, png, webp)
curl -X POST "https://blackfoxus.ru/api/classify_message/" \
-F "text=Super offer!" \
-F "image=@photo.jpg"

POST /api/classify_nsfw_image/

https://blackfoxus.ru/api/classify_nsfw_image/

Проверка изображения на наличие порнографических материалов.

curl -X POST "https://blackfoxus.ru/api/classify_nsfw_image/" \
-F "file=@image.jpg"

POST /api/classify_text/

https://blackfoxus.ru/api/classify_text/

Быстрый анализ только текстовой части.

curl -X POST "https://blackfoxus.ru/api/classify_text/" \
-H "Content-Type: application/json" \
-d '{"text": "Buy our services"}'
